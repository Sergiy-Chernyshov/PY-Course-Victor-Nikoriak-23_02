Excel Report Generator

Вебзастосунок для автоматизації обробки Excel-файлів та формування аналітичних звітів у форматах Excel і PDF.

Проєкт створений як фінальна робота курсу Python Developer та демонструє практичне використання Python, Django, Pandas та OpenPyXL для вирішення реальних бізнес-задач.

Призначення проєкту

У багатьох компаніях значна частина звітності ведеться в Excel. Ручна обробка великих файлів займає багато часу та часто призводить до помилок.

Метою проєкту є автоматизація:

аналізу даних із Excel;
класифікації записів за бізнес-правилами;
формування зведених звітів;
створення готових Excel та PDF документів;
скорочення часу підготовки звітності.

Особливості реалізації
Унікальні імена файлів

Для кожного завантаження використовується UUID:

uuid4().hex

Це запобігає конфліктам назв файлів.
